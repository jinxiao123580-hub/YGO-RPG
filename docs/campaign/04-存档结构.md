# 存档结构 v1

存档 = 单个 JSON 文件（战役状态） + `ygo_campaign.db`（收藏/卡池/抽卡日志, 已由工具维护）。
GM 每场景结束输出存档块, 人工确认后落盘到 `saves/<campaign_id>/save_ch<章>_<场景>.json`。

```json
{
  "campaign_id": "ygo_ruins_001",
  "schema": 1,
  "updated_at": "2026-10-10T20:00:00+08:00",
  "progress": {
    "chapter": 1,
    "scene": "2B",
    "awakening": 10,
    "unlocked_summoning": ["normal"],
    "unlocked_pools": ["ch1_pool_dragon", "ch1_pool_staple"],
    "next_chapter_gate": "awakening>=25"
  },
  "player": {
    "name": "?",
    "style": "白龙使",
    "stats": { "guts": 1, "wits": 1, "bond": 1 },
    "skills": [],
    "lp_carry": null
  },
  "bonds": { "晓": 1, "磨坊": 2 },
  "flags": {
    "ch1_cleared": true,
    "met_xiao": true,
    "awakening_1": false
  },
  "npc_states": {
    "磨坊": { "defeated": true, "difficulty_now": "AI_LV1", "loss_streak": 0 }
  },
  "duel_log_refs": ["ygo_campaign.db#draw_log", "MDPro3 replays/"],
  "notes": ["白龙卡全程未喊出真名", "晓伏笔: 瞳孔(x) 遗迹熟悉(o)"]
}
```

要点:
- **flags 与 `plot_flags` 表同源**: GM 置位走 `pool_draw` 接口, 存档块只做快照, 两边以 flags 表为准
- **loss_streak 驱动放水**: 同 NPC 连败 2 次 → GM 换用该 NPC 的降档 bot 条目
- **重复章/支线**: flags 里记录, 绝不让 GM 凭记忆记进度
