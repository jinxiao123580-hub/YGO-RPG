# 第一章剧本《旧货店的相遇》分镜稿

> 教学: 基本规则（抽卡阶段/通召/表示形式/攻击宣告/通常魔法陷阱）
> NPC: 店主·磨坊（MokeyMokey 卡组, AI_LV1） | 预计时长: 30-45 分钟
> 改编自: 《牛戏王：卡片芝力》第一集"安利"桥段 + 决斗者王国篇"命运之卡"桥段

## 场景 0 · 冷开场（GM 独白）

```
放学路上的旧货街尽头，有一家下午五点就打烊的店——「磨坊古董堂」。
玻璃柜里没有价签，只有一张落灰的卡：一条白龙，卡面却没有名字。
你伸手碰到卡的瞬间，店里传来一声——
「客人！你看到了什么？」
店主·磨坊从柜台后面弹起来，眼镜片反着光。
```

**玩家自由行动**（跑团层）:
- 观察卡片 →【学识检定】成功: 察觉卡面浮纹是"仪式阵的残片"（伏笔第七章）; 失败: 只觉得"挺帅"
- 询问店主 → 磨坊开始吹牛（喜剧段）: "这是我当年从决斗者手里赢来的！"
- 直接离开 → 卡片发出微光拉回视线（L0 演出, 强制钩子）

**必触发**: 磨坊提出"想让它认主，就得证明你懂决斗。来一局，我用我的收藏陪你练练。"

## 场景 1 · 教学决斗 VS 店主·磨坊

**开局演出**（GM 念）: "古董堂的后屋，一张老式决斗桌自己亮了起来。白龙卡在你手心微微发烫。"

**MDPro3 设置**: 本地 AI 房 · `店主·磨坊` 条目 · LP8000 · 玩家先攻

**教学节奏**（GM 按决斗事件逐条插入讲解，用磨坊的口吻）:
| 事件 | GM 台词模板 |
|---|---|
| 首次抽卡 | "决斗从抽卡开始！每一回合，你只能通召一次怪兽——记住，**一次**！" |
| 玩家通召 | "表示形式选攻击表示还是守备表示？攻击能打人，守备能挨打——新人都选攻击，因为**挨打很痛**。" |
| 对手盖卡 | "他盖了张卡？别怕，**盖着的卡要翻开才能用**。当然……也可能是在装样子。悠悠最会装样子了。" |
| 首次攻击宣告 | "攻击宣言！注意打守备怪兽时，**比的是攻击力和守备力**，打空门才看生命值！" |
| LP 首次下降 | "这就是伤害。心疼吗？心疼就对了，所以别乱攻。" |

**放水暗线**: MokeyMokey+LV1 天然放水。若玩家 LP<2000，GM 追加 L0 演出: 磨坊"手滑"念错效果（不影响引擎）。

**分支**:
- **胜**: 场景 2A
- **负**: 磨坊大笑，白龙卡却更烫了——"它不服气呢。再来！"（剧情免费再战, 第二局磨坊台词自带认输倾向; 二连败 → 走"磨坊让半血"房参（L1: LP4000）, 叙事"我让你四千点, 这是店规"）
- **平局/长时间**: 磨坊主动认输（"哎哟我孙子打电话叫我吃饭了"）

## 场景 2A · 白龙认主（奖励桥段）

```
磨坊收起卡组，忽然正色:
「这张卡在等一个人。等一个……把它打到最强的人。」
他把无名白龙卡和一叠卡推到你面前。
「店规: 试炼者带走卡，也带走试炼。遗迹在东边，八扇门。」
「打赢八位守门人，龙的真名就会醒来。」
```

**奖励发放**（调 pool_draw 接口, GM 逐张念出卡文）:
1. **剧情卡: 无名白龙**（= 青眼白龙, `unlock_plot: awakening_1` 沉睡——状态栏显示"它还没有醒来", 第二章通关后苏醒）← 关键卡不走随机, 剧情必给
2. **新手包 ×3**: 从 `ch1_pool_dragon` + `ch1_pool_staple` 抽（抽卡演出: GM 描述"古董堂的老抽卡机咔啦作响…"）
3. **剧情 flag 置位**: `ch1_cleared`, `met_xiao`

## 场景 2B · 钩子（离店）

```
出门时，一个少年在门口差点撞上你。他盯着你的包——不, 是盯着包里的卡。
「……白龙？」少年瞳孔缩了一下, 又立刻笑起来, 「没什么, 我叫晓。你也要去遗迹吗？正好, 同路。」
【羁绊检定】成功: 察觉他放下了防备（+1 羁绊）; 失败: 只觉得这小子行踪可疑（伏笔保留）
```
