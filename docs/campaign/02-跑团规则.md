# 跑团规则《决斗者遗迹》—— 决斗之外的世界规则

> 改编自通用轻量 2d6 框架（PbtA 系"属性+2d6≥8 成功"公开惯例），叠加决斗触发与羁绊系统。
> 原则: **决斗是唯一的"战斗系统"**——一切冲突最终落到牌桌上；跑团层负责走到牌桌之前的一切。

## 一、角色卡（决斗者档案）

```json
{
  "name": "玩家名",
  "style": "白龙使",            // 流派, 影响卡池偏好叙事
  "stats": { "guts": 1, "wits": 1, "bond": 1 },   // 胆识/学识/羁绊, 0-3
  "skills": [],                // 决斗者技能(每场一次), 由剧情获得
  "bond_web": { "晓": 1, "磨坊": 1 },              // 羁绊网
  "awakening": 0               // 白龙觉醒度 0-100
}
```

属性用途: **胆识**=迎难而上的行动（跳崖/质问/顶着压力抽卡）; **学识**=调查/考据/看穿卡路; **羁绊**=说服/求助/读懂人心。初始各 1, 每章结算 +1 点自由分配（上限 3）。

## 二、检定（决斗外一切行动）

```
2d6 + 属性 ≥ 8    成功
2d6 + 属性 ≥ 11   大成功(额外信息/奖励)
2d6 + 属性 ≤ 7    失败→剧情推进(GM 二选一: 付出代价成功 / 失败但局面变化)
```

- **失败不卡关**: PbtA 原则"失败推动剧情"——门开不了就走侧道，侧道遇到更强的怪（可跳过）
- 羁绊 ≥2 的 NPC 在场时, 可花 **1 羁绊**重掷一次（每人每场景一次）

## 三、场景循环

```
GM 描述场景 → 玩家自由行动(对话/调查/检定)
   → 触发冲突点 → [决斗] (MDPro3 本地 AI 房, GM 同步解说)
   → 结算: 胜利拿奖励 / 失败走分支表 → 换场景, 存档
```

决斗**不使用检定**进入——冲突点到了就打, 打完无论胜负剧情都前进（玩家角色不会死亡, 最坏后果见分支表）。

## 四、决斗败北分支表（GM 掷 d6）

| d6 | 后果 |
|---|---|
| 1 | 受伤: 下一场决斗开局少抽 1 张（叙事: 缠着绷带） |
| 2 | 破财: 随机失去 1 张非剧情卡（可后续赢回） |
| 3 | 被跟踪: 下章开场遭遇战（NPC 主动挑战） |
| 4 | 时间流逝: 某支线关闭（GM 标记一个可选内容 off） |
| 5 | 伙伴遇险: 晓被扣留, 下章必打救援局 |
| 6 | 被迫立誓: 接受一个剧情限制（"不能再使用速攻魔法, 直到下章"） |

## 五、场外支援（羁绊的战斗价值）

多人游玩时, 非决斗玩家每人每局可发动**一次**:
- **递话**: GM 提示对手盖卡的性质（攻击/效果, 不说卡名）
- **应援**: 决斗者抽卡阶段前改为从牌库顶 2 张选 1（模拟 MD 技能"命运抽卡"）
- **陪斗**: 立刻结束当前决斗重开, 但对手 LP 恢复满（救急用）

单人时, 羁绊 ≥2 的在场 NPC 自动代行"递话"。

## 六、觉醒度（三合一进度条）

| 觉醒度 | 事件 |
|---|---|
| 0 | 无名白龙（沉睡） |
| 10 | 第 1 章通关: 卡开始发烫 |
| 25 | 第 2 章通关: **苏醒为"青眼白龙"**, 卡文浮现 |
| 45/65/85 | 随章节浮现"新的纹章"（对应新召唤法教学钩子） |
| 100 | 第 8 章: 真名完全体（L2 剧情卡「苏醒的青眼」可发动） |

觉醒度来源: 主线胜利 +10~15 / 支线 +5 / 检定大成功 +2 / 羁绊事件 +3。
