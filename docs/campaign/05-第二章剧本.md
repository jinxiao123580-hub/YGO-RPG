## 场景 0 · 石门之前（GM 独白 + 自由行动）

```
东行半日，遗迹的第一道门矗立在崖壁之间——高十丈的整块黑岩，
门面上刻着一行字：『以弱者为阶，方见石后之天』。
一个身影从门后走出，通体覆着石纹般的外壳，声音像两块岩石相磨：
「试炼者。我是门卫·巨石。此门的规矩只有一条——
  你的卡组里，还没有能跨过这道门的力量。
  上级召唤：把弱小的怪兽作为祭品，唤醒真正强大的存在。
  学会它，门就开。学不会，就一直在门外。」
```

**玩家自由行动**:
- 观察门上的刻字 →【学识检定】成功: 察觉刻痕比遗迹本身**新**（有人近期刻上去的——伏笔: 黑衣决斗者在利用遗迹）; 失败: 只觉得古老庄严
- 询问"你是谁造的" → 巨石: "石门不回答关于造物主的问题。"（ firmly 挡回, 保留悬念）
- 晓的反应【自动触发】: 晓主动上前"我陪你打。放心, 这家伙的卡组我见过。"（+1 羁绊; 玩家若追问"你怎么见过"→ 晓移开视线: "……直觉。"）

## 场景 1 · 教学决斗 VS 门卫·巨石

**开局演出**: "石门前升起两根石柱，卡组各自落定。巨石的眼缝里透出微光：『试炼，开始。』"

**MDPro3 设置**: 本地 AI 房 · `战役-门卫巨石` · **LP16000**（L1 房参超规则: "石之门的试炼用古法——双倍生命, 磨的是耐性"）· 玩家先攻

**教学节奏**（巨石口吻, 按事件插入）:
| 事件 | GM 台词模板 |
|---|---|
| 玩家手牌出现 5 星以上怪兽 | "看着它。五颗星。寻常召唤唤不出它——**需要祭品**。" |
| 玩家首次祭品召唤 | "一换一，不亏。弱小者的价值, 就是成为台阶。记住此刻的手感。" |
| 玩家祭品召唤 7 星以上 | "两换一……你舍得。舍得的决斗者, 才配走进石门。" |
| 巨石召唤青蛙守备表示 | "石之守卫不求杀伤, 只求**站着**。守备表示, 挨打的艺术。" |
| 玩家攻击守备怪兽 | "打守备的东西, 比的是**守备力**。疼吗？石头不疼。" |
| LP 率先跌破 4000（任一方） | "古法双倍生命——急不得。石门的试炼磨的是**耐性**, 不是蛮力。" |

**放水暗线**: Frog+LV1 天然温和。若玩家连败 2 次 → 换 `战役-门卫巨石-让半血` 条目（如无此条目, GM 直接用房参 LP4000 重开, 叙事: "石头看你可怜, 减半"）。

**分支**:
- **胜**: 巨石低头, 石门中分开启 → 场景 2
- **负**: 巨石纹丝不动: "石门记住了你的样子。再来——石头有的是时间。"（免费再战; 二连败 → 半血房参）
- **平局**: 巨石罕见地顿了一下: "……平局也是通过。石门只看你是否理解了祭品。"（直接过关, 隐藏成就「不输不赢」）

## 场景 2 · 门后（奖励桥段）

```
穿过石门是一条向下的长阶。晓在回头望门顶的刻痕, 若有所思。
巨石的声音从背后传来, 第一次不像岩石:
「门后的人会考你更难的东西。还有——
  替我留意一个穿黑衣服的家伙。他来过。他不守规矩。」
```

**奖励发放**:
1. **觉醒度 +15**（→25: **白龙苏醒!** GM 郑重念出: 你手中那片鳞甲似的卡面泛起涟漪, 浮出四个字——**青眼白龙**。`unlock_plot: awakening_25` 置位, 白龙卡从"沉睡"变"可用"）
2. **新手包 ×3**: 从 `ch2_pool_rock` + `ch2_pool_staple` 抽（演出: "石门内侧的壁龛里, 嵌着一排落灰的卡"）
3. **解锁: 上级召唤**（`unlocked_summoning` 加入 tribute——之后玩家组卡可以放 5 星以上怪兽了）
4. **flag**: `ch2_cleared`, `black_robe_hint`（黑衣人伏笔, 第六章回收）, `xiao_suspect_1`（晓伏笔第二处）
